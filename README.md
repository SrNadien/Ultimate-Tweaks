# Ultimate Tweaks

The utility mod of the **Ultimate** family, for NeoForge.

Special items for modpack creators, which ship **without crafting recipes** so they can be wired up with KubeJS, plus two custom music discs and their sounds.

**Requires UltimateArmoury: Tools And Weapons.**

## Requirements

* NeoForge for Minecraft 1.21.1
* UltimateArmoury: Tools And Weapons

Optional: JEI, Jade.

## Branches

* `Neo/1.21.1` — Minecraft 1.21.1
* `Neo/26.1.2` — Minecraft 26.1.2
